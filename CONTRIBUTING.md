# Contributing

This is a **personal blog**, not a community project. There is no expectation of external contributions, and pull requests are not the default path.

## Preferred: open an issue

If you spot a typo, broken link, build problem, or small improvement worth noting, please [open an issue](https://github.com/nberardi/nickberardi.com/issues) on GitHub. A short description and URL are enough.

## Pull requests

Unsolicited PRs may be closed without merge. If you have a concrete fix and prefer a PR, keep it minimal, explain the change in the issue or PR description, and understand that acceptance is at the author’s discretion.
