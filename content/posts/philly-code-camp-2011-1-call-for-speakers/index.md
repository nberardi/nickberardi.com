![](http://coderjournal.com/uploads/2011/01/uncle_sam_2-300x280.jpg "Uncle Sam")**Philly Code Camp 2011.1** will be held **April 9th** at DeVry in Fort Washington. And we have a great line up of tracks this year, even a couple new web related tracks lead by John Petersen and Marc Ziss.

We always have a great turn out of interested and eager developers because **we have great topics, presented by even greater speakers**, and that is why **we cannot do it with out you, the speaker**.  So if you are interested in submitting a topic for one of the following tracks:

- Architecture
- Alt.Net
- ASP.Net
- SharePoint
- Framework
- Tools
- Data
- SQL & BI
- Beginner
- Mobile Apps

Or you can submit a topic for one of our new tracks this year:

- Web Framework (lead by John Petersen)
- Web Development ( lead by Marc Ziss)
- Silverlight (lead by John Angelini)

For the web framework and development track, **we are encouraging PHP and Ruby developers** in addition to .NET developers to submit talks this year.  Because PHP and Ruby has the same importance to the 800+ registered developers, that we get each time we hold a Code Camp, as any other language we typically have seen at Philly Code Camp.  So if you are, or know somebody that wants to speak on PHP or Ruby at Code Camp this year please have them [contact me](http://coderjournal.com/contact/) with any questions.

So if one of these tracks is your area of expertise or you have a great interest in speaking at Philly Code Camp this year, please submit your topic here by going here:

[**<http://codecamp.phillydotnet.org/2011-1/Lists/Speakers/AllItems.aspx>**](http://codecamp.phillydotnet.org/2011-1/Lists/Speakers/AllItems.aspx)

And clicking the “Add new item” button at the bottom of the page:

![image](http://coderjournal.com/uploads/2010/08/image.png "image")

We look forward to your submissions.  Because with out you, the speaker, Code Camp doesn’t work.
