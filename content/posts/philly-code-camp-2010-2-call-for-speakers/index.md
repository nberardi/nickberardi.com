We have a great line up of tracks this year, even a new one led by our very own, Philly area Microsoft Developer Evangelist, [Danny Diaz](http://smallandmighty.net/).  **This is our 5th year in a row hosting Code Camp for the Philly area**, and each and every year we have a great turn out, with over 500 developers showing up last time.  We have this great turn out because **we have great topics, presented by even greater speakers**, and that is why **we cannot do it with out you, the speaker**.  So if you are interested in submitting a topic for one of the following tracks:

- Alt.NET
- Architecture
- ASP.NET ([more info about what sessions I hope to have in this track](http://coderjournal.com/2010/08/philly-code-camp-2010-2-asp-net-track/))
- Silverlight
- SharePoint
- Visual Studio
- Framework
- Tools
- Data
- SQL & BI
- Beginner
- IT
- Windows Phone

If one of these tracks is your area of expertise or you have a great interest in speaking at Philly Code Camp this year, please submit your topic here by going here:

[**<http://codecamp.phillydotnet.org/2010-2/Lists/Speakers/AllItems.aspx>**](http://codecamp.phillydotnet.org/2010-2/Lists/Speakers/AllItems.aspx "http://codecamp.phillydotnet.org/2010-2/Lists/Speakers/AllItems.aspx")

And clicking the “Add new item” button at the bottom of the page:

![image](http://coderjournal.com/uploads/2010/08/image.png "image")

We look forward to your submissions.  Because with out you, the speaker, Code Camp doesn’t work.
