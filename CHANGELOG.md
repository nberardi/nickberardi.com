# Changelog

High-level history of [nickberardi.com](https://nickberardi.com). Entries summarize major phases, not every commit.

## 2026-02-18 — Initial commit (`a419d647`)

Full migration of **327 posts** and **1,468 images** from Ghost 0.5.7 to Hugo with the PaperMod theme. Custom Python conversion preserved metadata and original URL structure; images moved to static assets; GitHub Pages workflow and custom-domain setup established.

## 2026-07-30 — Return to publishing

First new post in about twelve years (“Twelve Years Later”). Added `AGENTS.md` / `CLAUDE.md` so publishing stays consistent for humans and AI-assisted workflows.

## 2026-08-02 onward — Broadsheet redesign

Major redesign to the custom Broadsheet design system: left-rail layout, cover images, Open Graph cards (build-time render with fail-soft defaults), image classification, click-to-zoom, and related post-rendering polish. Ongoing redline fixes and quality work continue on this foundation.
