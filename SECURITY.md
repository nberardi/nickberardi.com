# Security

If you believe you have found a security issue in this site or its build/deploy setup, please report it **privately**—do not open a public issue.

**Preferred:** use [GitHub private vulnerability reporting](https://github.com/nberardi/nickberardi.com/security/advisories/new) for this repository, if available.

**Alternative:** contact the site owner via [nickberardi.com](https://nickberardi.com) (see the About page or site contact details).

Please include enough detail to reproduce the issue and avoid sharing exploit details in public channels until it can be addressed.
