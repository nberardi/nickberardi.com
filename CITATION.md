# Citing this site

**Nick Berardi’s personal blog** at [https://nickberardi.com](https://nickberardi.com).

When you cite a specific post, use that post’s **title**, **publication date**, and **URL** rather than only the site as a whole. The formats below cover both the site and a single-post example.

## APA (7th edition)

### Entire site

Berardi, N. (n.d.). *Nick Berardi*. https://nickberardi.com

### Individual post (example)

Berardi, N. (2026, July 30). *Twelve years later*. Nick Berardi. https://nickberardi.com/posts/twelve-years-later/

Replace the year, month, day, title, and URL with those of the post you are citing.

---

## BibTeX

### Entire site

```bibtex
@misc{berardi_blog,
  author       = {Berardi, Nick},
  title        = {Nick Berardi},
  howpublished = {\url{https://nickberardi.com}},
  note         = {Personal blog},
  year         = {n.d.}
}
```

### Individual post (example)

```bibtex
@misc{berardi2026twelve,
  author       = {Berardi, Nick},
  title        = {Twelve Years Later},
  howpublished = {\url{https://nickberardi.com/posts/twelve-years-later/}},
  year         = {2026},
  month        = jul,
  day          = {30},
  note         = {Personal blog post}
}
```

Adjust `title`, `howpublished`, `year`, `month`, and `day` for each post.
